# 股票数据采集器

输入股票名称、6 位代码，或直接粘贴东方财富页面地址即可查询。例如：

- `https://quote.eastmoney.com/f1.html?newcode=0.301307`：分时成交/逐笔页面
- `https://quote.eastmoney.com/sz300059.html#fullScreenChart`：日线页面

支持：

- 当日分时成交，数据截止到当前接口返回时间
- 当日完整逐笔成交，包含时间、价格、成交量和买卖方向
- 最近约两年日线数据，界面显示最近 60 个交易日
- MA、MACD、RSI、KDJ、BOLL、ATR、OBV、量比和阶段收益
- 与上证指数、深证成指或创业板指的阶段超额收益比较
- 主交易分时 VWAP、主动买卖量和净主动量；竞价快照与盘后定价单列
- 最近 31 天龙虎榜
- 基于 OHLCV 的估算筹码分布和平均成本
- 可选的接口测试（仅界面显示，不写入导出报告）
- 导出日线指标 CSV、基准指数 CSV、分时 CSV、逐笔 CSV 和分析 JSON

页面地址本身是 JavaScript 展示页，HTML 只返回页面框架。逐笔数据使用东方财富 f1 页面对应的明细接口，以 `pos=0` 获取当天全量；如果东方财富暂时不可用，才切换到腾讯约 3 秒汇总数据，并明确标记为备用口径。09:25 前的集合竞价记录是行情快照，不累计为成交量；15:00 后的盘后定价交易单独统计。东财逐笔接口不提供精确成交额，因此“金额”保留空值，另列“估算金额”和口径，避免把估算值冒充原始值。

## 运行

```powershell
cd D:\CodexProjects\eastmoney_stock_spider
python stock_spider.py
```

也可以自检：

```powershell
python stock_spider.py --self-test 301307
```

筹码分布为估算口径，不应视为交易所原始持仓数据。不同软件可能使用不同数据源、复权方式、成交口径和更新时间。

导出文件用途：

- `*_daily_indicators.csv`：约两年逐日 OHLCV、前复权/不复权价格、复权因子、精确成交额、历史流通股本、精确历史换手率、盘后成交量/额、理论涨跌停和技术指标；估算金额/换手率仅作备用
- `*_benchmark.csv`：对应宽基指数日线，用于计算相对强弱和超额收益
- `*_intraday.csv`：当日分钟价格、分钟成交量和分钟成交额，含交易阶段与主交易统计标记
- `*_details.csv`：当日逐笔及买卖方向，含序号、交易阶段、记录性质、估算金额与统计标记
- `*_analysis.json`：当前快照、阶段收益、趋势、动量、波动、量价、成交阶段汇总和数据质量检查

为了避免生成重复文档，Markdown 报告、单独的成交汇总 CSV 和单独的数据质量 CSV 已停止生成；相应汇总统一保存在 `*_analysis.json` 中。

当前含宽基指数比较，但没有精确的所属行业指数和同业排名；也没有财务估值、公告新闻、资金流和融资融券数据，因此报告不会把这些内容伪装成已有结论。
